# Text Kit

Учебный проект для обработки строк, чисел, проверки данных и работы с датами.

## Структура проекта

```text
text-kit/
├── app/
│   ├── __init__.py
│   ├── main.py                  # Точка входа (запуск программы)
│   ├── utils/
│   │   ├── __init__.py
│   │   ├── text.py              # Работа со строками (пробелы, инициалы, slug)
│   │   └── dates.py             # Работа с датами (парсинг, форматирование)
│   └── services/
│       ├── __init__.py
│       ├── statistics.py        # Математические расчеты (среднее, медиана)
│       └── validation.py        # Проверка данных (email, телефоны, пароли)
├── tests/                       # Юнит-тесты
└── README.md
