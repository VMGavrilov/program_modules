# Учёт расходов в поездке

Программа для расчета общих и средних расходов во время поездки.

## Команды для запуска

1. Создать виртуальное окружение:
   `py -m venv .venv` (или `python3 -m venv .venv`)

2. Активировать окружение:
   `.venv\Scripts\activate` (или `source .venv/bin/activate`)

3. Установить зависимости:
   `pip install -r requirements.txt`

4. Запустить программу:
   `py trip.py` (или `python3 trip.py`)

## Что печатает программа

Программа выводит отчет:
- ОТЧЁТ ПО ПОЕЗДКЕ (выделен зеленым жирным шрифтом)
- количество записей
- общую сумму расходов
- среднюю трату
